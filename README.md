### ⚡ [WhyCode](https://github.com/Nithaesh/why-code): Codebase Intelligence & Software Archaeology
*Solo project*

Ask questions about **any public GitHub repository** and get answers backed by verified citations. WhyCode combines compiler AST dependency graphs, Git revision blame and hybrid search (BM25 + Gemini embeddings fused with Reciprocal Rank Fusion). A post-generation citation verifier audits every claim against the files on disk, and an autonomous multi-hop ReAct agent investigates complex questions across AST, commits and search.

- 171 automated tests running fully offline, plus a security audit (path traversal, command injection, prompt injection)
- React 19 + TypeScript + Tailwind v4 web studio served by FastAPI, with a CLI and REST API

### 🚗 [ADAS Perception Pipeline](https://github.com/Nithaesh/adas-perception-pipeline): Lane Detection & Vehicle Perception
*Solo project*

A road-scene perception system built to explore the core ideas behind Advanced Driver Assistance Systems. It detects lanes with classical computer vision (Canny + Hough), projects a dynamic perspective distance grid, detects vehicles and pedestrians with YOLOv8, and estimates each object's distance from a single camera using the pinhole model.

- Fallback safety grid keeps distance guidance visible when lane detection fails
- GPU-accelerated inference with CUDA, producing annotated output video

### 🍲 [RePlate](https://github.com/Nithaesh/Replate): Food Rescue & Donation Platform
*Full-stack, solo project*

A real-time, geolocation-based platform that connects restaurants, hotels and individual donors with nearby NGOs to reduce food waste. Donors can broadcast to all NGOs in a 15 km radius or donate directly to one, and NGOs get an operations dashboard with a live map and one-click acceptance. Chat unlocks once a donation is accepted, and an admin panel handles NGO verification.

- Role-based dashboards for Donors, NGOs and Admins
- Live status tracking: Accepted → Pickup in Progress → Completed

### 🌆 [Nagar-Drishti](https://github.com/upadhyayom1/Nagar-Drishti): Urban Traffic Intelligence
*Team project: frontend & ML engineer* · [🔗 Live Demo](https://nagardrishti.vercel.app)

An AI-powered platform that analyzes vehicle movement across multiple camera points. It runs automatic number-plate recognition, monitors blacklisted vehicles, flags unusual movement patterns, predicts the next likely camera sighting, and forecasts traffic volume per camera, all in one dashboard.

- ANPR pipeline with YOLO + EasyOCR, anomaly detection (Isolation Forest, DBSCAN) and Random Forest traffic forecasting
- Unified dashboard with alerts, trends and vehicle trajectories
